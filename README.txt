ROMANTIC CONFESSION WEBSITE
=============================

Struktur:
- main.html
- style.css
- app.js
- assets/images/foto-1.jpg sampai foto-5.jpg
- assets/music/our-song.mp3

CARA MENGGANTI FOTO
1. Siapkan 5 foto JPG.
2. Ubah nama fotonya menjadi:
   foto-1.jpg
   foto-2.jpg
   foto-3.jpg
   foto-4.jpg
   foto-5.jpg
3. Masukkan ke folder assets/images.
4. Timpa file placeholder yang sudah ada.

CARA MENGGANTI MUSIK
1. Siapkan musik format MP3.
2. Ubah namanya menjadi our-song.mp3.
3. Masukkan ke folder assets/music.

CARA MENGGANTI NAMA DAN ISI SURAT
Buka main.html, lalu cari teks:
- "Nama Kamu"
- paragraf cerita
- pertanyaan terakhir

CATATAN MUSIK
Browser modern memblokir autoplay bersuara.
Musik akan otomatis mulai setelah pengunjung menyentuh layar,
menekan tombol, atau melakukan interaksi pertama.

CARA MENJALANKAN
Cukup buka main.html di browser.

UNTUK NETLIFY
Agar halaman langsung terbuka saat deploy:
- Ubah nama main.html menjadi index.html
- Upload seluruh isi folder, bukan folder luarnya saja.


FITUR BACKGROUND BARU
- Hujan love bergerak dari atas ke bawah.
- Sparkle putih dan biru yang berkelip.
- Kabut biru cinematic bergerak perlahan.
- Efek vignette agar tampilan terasa seperti film.
- Sudah responsif dan lebih ringan di HP.
